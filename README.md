# Beautiful Soup Python Project

This project is a Python application that utilizes Beautiful Soup for web scraping and HTML parsing.

## Project Structure

```
beautifulsoup-python
├── main.py          # Main application logic
├── main.test.py     # Unit tests for the application
├── requirements.txt      # Project dependencies
├── Jenkinsfile           # CI/CD pipeline configuration
└── README.md             # Project documentation
```

## Installation

To get started with this project, you need to have Python installed on your machine. You can install the required dependencies using pip:

```bash
pip install -r requirements.txt
```

## Usage

To run the application, execute the following command:

```bash
python main.py
```

## Running Tests

To run the unit tests, use the following command:

```bash
python -m unittest discover -s tests
```
